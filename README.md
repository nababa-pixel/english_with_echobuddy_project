เว็บแอปพลิเคชันสำหรับช่วยฝึกทักษะภาษาอังกฤษ พร้อมระบบวิเคราะห์และแจ้งเตือนข้อผิดพลาดด้านแกรมม่าที่พบบ่อย (Common Errors) และระบบแนะนำคำศัพท์ใหม่จากบทสนทนา เพื่อให้ผู้เรียนพัฒนาทักษะได้อย่างตรงจุด

### สถานะงานและฟีเจอร์หลัก (Features & progress)
* ✅ **ระบบจัดการข้อมูลผู้ใช้งาน (User Management):** บันทึกและดึงข้อมูลผู้ใช้งานผ่านฐานข้อมูล (`User_data.db`)
* ✅ **ฐานข้อมูลข้อผิดพลาดที่พบบ่อย (Common Errors Database):** รวบรวมรูปแบบประโยคที่มักใช้ผิด (`common_errors.db`)
* ✅ **หน้าเว็บไซต์หลักและโครงสร้างพื้นฐาน:** ออกแบบหน้าแสดงผล (`index.html`, `page2.html`, `profile.html`, `tasks.html`) และเชื่อมต่อระบบหลังบ้าน (`backend.py`)
* 🔄 **กำลังพัฒนา (In Progress):** ปรับปรุงระบบโต้ตอบอัตโนมัติ (EchoBuddy) และเพิ่มคลังแบบฝึกหัดให้ครอบคลุมยิ่งขึ้น
